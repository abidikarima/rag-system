# RAG Retrieval Evaluation

Retrieval methods compared on two test sets of 300 questions. The question
sets are described in [test_data.md](test_data.md).

## Setup

| | |
| --- | --- |
| Test sets | `test_data/claude_test_questions.jsonl` (written by Claude, `claude-opus-5-5`), `test_data/groq_test_questions.jsonl` (generated by Groq, `openai/gpt-oss-120b`) |
| Questions | 300 per set, one chunk from each of 300 documents, 100 `easy` / 100 `medium` / 100 `hard` |
| Index | `chroma_db_v1`, 5,608 chunks |
| Script | `uv run python -m ragsystem.evaluation.evaluate_combinations --test-file <test set>` |
| Output | `results/combination_evaluation_<test set name>.json` |

## Metrics

| Metric | Definition |
| --- | --- |
| chunk@k | The expected chunk is in the top k results |
| doc@k | At least one chunk of the expected document is in the top k results |
| MRR | Mean of 1 / rank of the expected chunk |

## Signals

| Signal | Compared with the question |
| --- | --- |
| Embedding | Qwen3 dense embedding of the chunk text (cosine) |
| Sparse | SPLADE sparse vector of the chunk text (dot product) |
| Summary embedding | Qwen3 dense embedding of the chunk's LLM summary |
| Summary sparse | SPLADE sparse vector of the chunk's LLM summary |

## Fusions

| Fusion | Ranking |
| --- | --- |
| Score average | Each signal's scores are min-max normalized over the collection, then averaged with equal weights. Used by every method without a prefix |
| Common first | Each signal takes its own top 10 chunks. Chunks found by all signals rank first, then chunks found by fewer signals, then the rest; within a group, by score average |
| RRF | Reciprocal rank fusion: sum over the signals of 1 / (60 + rank) |
