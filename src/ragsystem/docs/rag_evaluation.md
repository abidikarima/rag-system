# RAG Retrieval Evaluation

This document reports how well the retrieval part of the RAG system finds the
right chunk for a question. Seven retrieval methods are compared on two test
sets of 300 questions each:

- **Claude test set**: `test_data/claude_test_questions.jsonl`, questions
  written by Claude.
- **Groq test set**: `test_data/groq_test_questions.jsonl`, questions
  generated by the Groq LLM.

Each test set takes one chunk from each of 300 different documents, with 100
`easy`, 100 `medium` and 100 `hard` questions. How the questions are created is
explained in [test_data.md](test_data.md).

## Retrieval methods

Each method scores every chunk of the collection against the question.

| Method                     | What is compared with the question                        |
| -------------------------- | --------------------------------------------------------- |
| Embedding only             | Qwen3 dense embedding of the chunk text                   |
| Sparse only                | SPLADE sparse vector of the chunk text                    |
| Embedding + sparse         | Both of the above, scores normalized and averaged (50/50) |
| Summary embedding          | Qwen3 dense embedding of the chunk's LLM summary          |
| Summary sparse             | SPLADE sparse vector of the chunk's LLM summary           |
| Summary embedding + sparse | Both summary signals, averaged (50/50)                    |
| All four                   | All four signals, averaged (25% each)                     |

## Metrics

- **chunk@k**: the expected chunk is in the top k results (main metric).
- **doc@k**: at least one chunk of the expected document is in the top k.
- **MRR** (mean reciprocal rank): average of 1 / rank of the expected chunk.
  1.0 means it is always ranked first.

# Combination Evaluation: Claude Test Set

## Setup

|                 |                                                                                                                 |
| --------------- | --------------------------------------------------------------------------------------------------------------- |
| Test set        | `test_data/claude_test_questions.jsonl`: 300 questions written by Claude (`claude-opus-5-5`)                    |
| Coverage        | one chunk from each of **300 different documents**                                                              |
| Difficulty      | 100 `easy`, 100 `medium`, 100 `hard`                                                                            |
| Index           | `chroma_db_v1`, 5,608 chunks                                                                                    |
| Script          | `uv run python -m ragsystem.evaluation.evaluate_combinations --test-file test_data/claude_test_questions.jsonl` |
| Detailed output | `results/combination_evaluation_claude_test_questions.json`                                                     |

How the questions were selected and written is explained in
[test_data.md](test_data.md).

| Coverage        | one chunk from each of **300 different documents**                                                                                    |
| Difficulty      | 100 `easy`, 100 `medium`, 100 `hard`                                                                                                  |
| Index           | `chroma_db_v1`, 5,608 chunks                                                                                                          |

| Detailed output | `results/combination_evaluation_groq_test_questions.json`                                                                             |

**Overlap with the Claude test set.** The two sets share **294 of their 300
chunks**, so the overall results can be compared. However, only **124** of
those shared chunks have the same difficulty level in both sets. The
per-difficulty tables of the two sets therefore cover mostly different chunks.
